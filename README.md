# Ebook-Calculo-Vol1-9Ed
Repository dedicated to the study of *Calculus: Early Transcendentals, Volume 1 (9th Edition)* by James Stewart, Daniel Clegg, and Saleem Watson. It includes organized notes, summaries, solved exercises, and practical examples, focusing on a clear and progressive understanding of fundamental concepts.
